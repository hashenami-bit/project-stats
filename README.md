# Project Stats (app)

A phone-friendly status board. **This repo holds no project data.** After you open it, it asks for a
GitHub fine-grained token and reads `status.json` from your private data repo. The token is stored only
in that device's browser storage.

- Edit `src.html`, then run `python3 build.py` (it adds the shared CSS from the Project Stats artifact page).
- Hosted with GitHub Pages from the `main` branch root.
